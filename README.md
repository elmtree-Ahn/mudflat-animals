# 갯벌 동물 탐험대

초등 3학년 과학 '갯벌에 사는 동물' 수업용 사진 갤러리 웹앱.
갯벌 동물 14종 + 갯벌 위·속 단면 그림. 칠게·엽낭게·갯우렁이는 '동물 / 흔적' 사진 비교.
